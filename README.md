# doc-app-trad-mentorat
Repos qui contient la documentation du projet d'apprentissage FR->AR mentoré

## Documentation HTML

Ouvrir `docs/index.html` dans un navigateur. Après modification d'un fichier `docs/*.md`, régénérer avec `node docs/build.mjs`.

## Squelette .NET

Solution .NET 10 en DDD et architecture hexagonale (`HexaApp.slnx`, `src/`, `tests/`), utilisable comme template `dotnet new`. Voir [ARCHITECTURE.md](ARCHITECTURE.md).
